# Chat Marks — releases

This repository publishes the **Chat Marks** desktop installers, the browser extension package and release notes.

- Download the latest version from the [Releases](https://github.com/mvclaudianobj/chat-on-steroids/releases) page.
- Installed copies of Chat Marks check this page for updates.
- Chat Marks is built on top of the open-source [Chat On Steroids](https://github.com/totec448-spec/chat-on-steroids) project (MIT License). The `main` branch here mirrors that community project.

Chat Marks source code is maintained privately.
