# Habblaud assets and pixel-art adaptation

Source: https://github.com/marmottajr/habblaud
Inspected revision: `faa1a012b5fbf632c66dc6801c5383e53a542406`.

Copyright (c) 2026 Márcio Junior. All Habblaud attribution retained.

The four art PNG files in `art/` were copied unmodified from
`client/public/assets/art/` and `client/public/assets/art/framed/`.
The code in `src/renderer/company-pixel-art.ts` adapts Habblaud's
`client/src/art/core/pixbuf.ts` ASCII stamp pattern and the procedural
character/furniture approach in `client/src/art/character` and
`client/src/art/furniture`. The layout in
`src/renderer/company-rpg-world.ts` adapts its
`client/src/world/layout` project-room, elevator and garden concepts.

The upstream README states that source art is generated by code and that
`client/public/assets` images were created with AI for that project. No
separate third-party asset license was found in the inspected repository.
Habblaud logo and brand assets were deliberately excluded; there is no
affiliation or endorsement by that project or any other organization.
