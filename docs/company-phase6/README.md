# O6 — Delegação operacional (2026-10-23)

Base O5 `0becbf7f`. Manual é o padrão também ao carregar snapshots O1-O5. O CEO pode ativar ou revogar expressamente, com confirmação nativa na janela principal, somente o escopo `ticket-review` para o cargo fixo `marks-coo`. O store mantém epoch durável e trilha de auditoria restrita (ator, evento, época, escopo, ID de ticket; sem conteúdo privado). A confirmação manual de revisão mantém verificação do broker; nenhuma permissão obrigatória de sistema ou serviço foi flexibilizada.

**Importante — integração ainda não habilitada para decisões COO reais:** o broker disponível demonstra identidade do trabalhador por owner/run/worker, mas não autentica uma identidade independente do cargo COO. Por isso, `reviewDelegated` é main-only, não existe no IPC exposto ao renderer, e falha sem prova autenticada. A função recebe um principal somente de integração interna confiável e refaz a verificação broker. Não tratar o botão de delegação como aprovação automática. O epoch é revalidado na transação final, recusando decisões iniciadas antes de uma revogação. A política pode ser ligada para uso futuro, mas sua execução fica bloqueada até existir provenance COO segura de ponta a ponta.

Quatro formatos de reunião: ad-hoc, emergência, diária e semanal. Convites são criados para todas as cadeiras configuradas; entrega real requer autorização humana e o broker, e presença continua a exigir confirmação individual. Nenhuma reunião é disparada por timer. Board, Escritório, painel CEO e RPG permanecem disponíveis.

Cobertura sintética: testes de snapshots legados, concessão/revogação/reload, spoofing IPC, identidade ausente, fencing de epoch em voo, principal synthetic injetado internamente, reuniões nos dois modos. **Não houve workers reais, autenticação de COO real nem testes em contas privadas.** Para liberar delegação efetiva, é necessário implementar um principal COO autenticado oriundo de canal broker/controle e validar end-to-end, preservando consentimento de ferramentas e demais serviços.
