# Rest room — Company office pilot

The Office now includes a Rest room containing only the first ten configured employee seats that pass the durable eligibility projection. Workers with no tickets are labelled **Free · no tasks**. Workers whose latest completed ticket has a matched worker report and separate `marks-coo` confirmation are labelled **Completed · COO confirmed**, with a direct action to inspect the ticket. All active, assigned, review-pending, CEO-pending, unresolved or unverified work suppresses rest. An active meeting invitation takes precedence over rest, distinguishing invited, accepted and confirmed-present statuses. Meetings continue to invite all configured seats; no invitation creates attendance.

`companySeatView` is computed from persisted requests, worker receipts, explicit COO confirmation and meeting invitations. Legacy done tickets without a matching receipt stay **Completion not verified**; existing `company.json` files load without destructive migration. Browser and IPC still refuse live worker `authorize`, `report`, `confirm` and meeting `attendance` until the authenticated broker/COO correlation adapter exists. Local store tests use synthetic identities and attestations only.
