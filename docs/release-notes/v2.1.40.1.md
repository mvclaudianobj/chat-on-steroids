## Chat Marks 2.1.40.1 — Modules, project navigation and packaging corrections

This maintenance release builds on 2.1.40 and includes the Marks-specific renderer and module integrations.

### Fixed

- MarksCode, Codex, Claude and MarksClaw module entry points are restored in the sidebar with the expected Marks branding.
- The module UI initializes before its navigation handlers are used.
- Project terminals remain visible after project list refreshes; project actions and menus are restored.
- Native release checks accommodate the MarksPanel login view while retaining renderer-startup failure checks.

### Distribution

- Windows x64/arm64, Linux x64/arm64 and macOS x64/arm64 packages are built by the release pipeline.
- The Chromium extension and Firefox add-on are versioned with the desktop application. The Firefox add-on is signed for its production identity by Mozilla during publishing.
- Windows and Linux update methods follow the application's supported installer mechanism; macOS updates are downloaded and installed manually.

### After updating

The app will make the matching browser extension available when no chat is busy. Existing user data is preserved by the regular installer.
