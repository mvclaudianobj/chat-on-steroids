## Chat Marks 2.1.45.1 — Comunidade v2.1.45 com os recursos Marks preservados

Integra a versão 2.1.45 da comunidade ao Chat Marks, sem substituir os recursos próprios do fork.

### Novidades da comunidade

- **Grupos de chats:** o menu ⋯ de um projeto tem **Novo grupo**. Mova um chat para um grupo pelo menu ⋯ dele (**Mover para grupo**), arraste os grupos na ordem que preferir e renomeie ou exclua um grupo pelo menu. Excluir um grupo mantém os chats no projeto.
- **Favoritos:** toda resposta concluída tem um botão de favorito ao lado de Copiar. Quando o chat tem favoritos, o cabeçalho mostra a contagem; escolha um para voltar àquela resposta.
- **Rascunhos que esperam por você:** um chat com mensagem pela metade mostra um lápis na barra lateral, e os rascunhos voltam depois de reiniciar ou atualizar.
- **Review: adicionar ao .gitignore:** clique com o botão direito num arquivo não rastreado para adicioná-lo, ou a pasta dele, ao .gitignore.
- **Blocos de código** mostram a linguagem, quebram linhas longas sob demanda e podem ser salvos como arquivo.
- **Terminal:** selecione a saída e envie para a caixa de mensagem como bloco de código. As abas do terminal voltam depois de reiniciar; **Iniciar shell aqui** abre de novo.
- **Uso por projeto e em arquivo:** Configurações → Uso mostra o consumo de cada projeto, e **Exportar CSV** salva a página como planilha.
- **Marcar tudo como visto:** um clique limpa todos os pontos de "Nova resposta", ou só os de um projeto pelo menu dele.
- **Conferir o "concluído" do Goal:** Configurações → Agentes e automação → **Revisar conclusão do Goal** (desligado por padrão) mantém o chat esperando por você quando o Goal diz que terminou.

### Melhorias e correções da comunidade

- Menos pedidos de permissão do ChatGPT: o texto do próprio conector deixou de ser marcado como "Instrução suspeita".
- Goal e Loop também veem a primeira mensagem do chat, para não perder requisitos do início em chats longos.
- Chats iniciados no chatgpt.com dentro de um Projeto vinculado aparecem no projeto correspondente do app.
- Windows: apps da Store recebem cliques e digitação com a janela do app na frente; apps abertos pelas ferramentas de desktop continuam abertos quando o auxiliar reinicia; a atualização automática do conector Desktop confirma com a lista completa de ferramentas.
- Ilustrações desenhadas pelo ChatGPT aparecem na cópia da resposta no app (somente do servidor de imagens do próprio ChatGPT).
- Conexão com o ChatGPT mais confiável: o cliente de túnel tenta de novo em falhas curtas ao iniciar.
- Cerca de 70 mensagens de erro passaram a ser traduzidas.
- Compact & Resume funciona no plano Free; comandos do PowerShell que imprimem tabelas devolvem a saída; um chat novo aguardando a primeira mensagem não aparece mais como "bloqueado"; mensagem para um chat cuja aba foi fechada sai em vez de esperar 15 minutos.

### Chat Marks

- **Rota por chat no Codex e no Claude Code:** o Claude Code Router se grava em `~/.claude/settings.json` e `~/.codex/config.toml`, e por isso todo chat do Codex e do Claude Code passava pelo roteador sem avisar. Agora cada chat tem uma rota: a conta da própria CLI (direta, padrão para chats novos) ou **Via Claude Code Router**, escolhida no compositor quando o roteador é detectado e mostrada no cabeçalho do chat. O app só lê esses arquivos e nunca os altera; os ajustes da rota direta valem apenas para os processos que ele inicia.
- **Chats existentes:** continuam na rota com que já rodavam (a configuração da CLI). Ao trocar de rota, o Claude Code mantém a mesma sessão; o Codex começa uma nova thread na outra rota e o histórico do chat permanece.
- **Nomes reais dos modelos:** a lista de modelos vem de cada rota e mostra o modelo concreto com a versão, por exemplo `opus (claude-opus-5-5)` ou `GPT-6.1-Sol (gpt-6.1-sol)`, em vez de apelidos soltos ou só o modelo do roteador.
- **ZeroClaw com página própria:** um item **ZeroClaw** logo abaixo de Mascotes na barra lateral (visível com o módulo ativado) abre uma página com Status, Configurar agente e Configurações. Em Configurações → Módulos ficam a instalação e a atualização, com link para a página.
- **Pacote de homologação (a detalhar):** cofre de segredos (K), notificações (I), Brain (H), módulo Claude Code Router, atualizações das CLIs (U), projetos remotos (L), VMs (N), empresa (O), Jarvis (J/J2) e importação do ZeroClaw (ZC).

#### Correções do Chat Marks

- **Configurar agente agora desenha:** o terminal da configuração abria sem altura e era recusado antes de iniciar. Agora ocupa a página, os tamanhos enviados ao app ficam dentro do aceito e, quando a configuração termina, a página avisa e mantém a última saída.
- **ZeroClaw não fecha mais antes de desenhar:** os terminais e as leituras de configuração do ZeroClaw rodam com `umask 077` e as pastas `~/.zeroclaw` e `~/.zeroclaw/data` perdem a permissão de escrita para grupo e outros, que o daemon do ZeroClaw 0.8.6 recusava.
- **Aviso de atualização da extensão correto:** a versão da extensão informada pelo app passa a ser a do navegador escolhido para o ChatGPT. Uma cópia antiga ainda ativa em outro navegador não pede mais para atualizar a extensão do navegador integrado.

#### Configuração

- **Claude Code direto:** os chats diretos do Claude Code usam a conta da própria CLI. Se o seu Claude Code passa pelo Claude Code Router e nunca teve login próprio, rode `claude auth login` uma vez; sem isso o envio direto é recusado antes de qualquer registro, com essa instrução. Para continuar pelo roteador, escolha **Via Claude Code Router** no chat.
- **Codex direto:** usa a conta ChatGPT em que a CLI do Codex está conectada (o provedor `openai` embutido) e o catálogo de modelos dessa conta.
- Sem Claude Code Router detectado, nada muda: as duas rotas são o mesmo processo e não aparece escolha. No Windows (CLIs dentro do WSL) o roteador ainda não é detectado.
