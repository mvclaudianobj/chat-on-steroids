## Chat Marks 2.1.54.30

The Local Control API remains local by default. When explicitly enabled, it can listen on the current IPv4 address of an approved WireGuard (`wg_zt`) or Tailscale interface so another trusted device on that overlay can connect. The app does not bind to every interface, add firewall rules, or silently switch addresses when the selected interface is unavailable. Per-run authentication and the independent “Allow actions” setting remain in force.

WhatsApp Web self-chat now dispatches exact supported commands such as `/menu` and `/ajuda`; ordinary notes and the app's own echoed messages are still ignored. Approval notices open the central Approvals page, where pending cards remain accessible even when their timeline card has scrolled out of view.
