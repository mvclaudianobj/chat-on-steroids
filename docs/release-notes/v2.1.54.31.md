## Chat Marks 2.1.54.31

Each account slot now has its own companion-browser listener and credential. The Chrome extension checks only the port for the selected slot; browser commands and revocation stay isolated to that slot.

Verified Company sessions can read a bounded, read-only page of another session's recorded history, including when it belongs to a different account slot. The app's native instructions now explain how to use Chat Marks' own session and control tools.

Disconnecting an external browser invalidates requests already in flight, so an old poll cannot restore its presence after revocation.
