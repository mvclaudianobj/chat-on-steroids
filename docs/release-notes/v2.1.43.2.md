## Chat Marks 2.1.43.2 — Chat com CLIProxy e módulo CLIProxyAPI completo

Revisão Marks sobre a comunidade v2.1.43.

### Novidades

- **Chat com CLIProxy:** em "Novo chat" → **CLIProxy**, ou no menu de um projeto → **Novo chat CLIProxy neste projeto**, converse com os modelos do CLIProxyAPI local na mesma tela de chat do Chat Marks. Resposta em tempo real, botão Parar, modelo e raciocínio por chat, histórico como qualquer outro chat e recuperação de uma resposta interrompida por reinício. Ele trabalha no projeto do chat com as ferramentas locais do app (ler, buscar, editar e rodar comandos), passo a passo, com as mesmas permissões de pastas, capacidades e comandos do ChatGPT. Edições e comandos pedem aprovação, a menos que o chat esteja em modo automático.
- **CLIProxyAPI gerenciado em Módulos:**
  - versões instalada e oficial, com instalar e atualizar pela release oficial e checksum verificado;
  - reparo, com confirmação, para um serviço existente conseguir salvar a configuração;
  - senha do console guardada uma vez (o console abre já autenticado);
  - chaves de API para criar (já salvas no chat CLIProxy) e revogar.
- **Novo chat em qualquer layout:** o botão de novo chat do layout Caixa de entrada oferece o mesmo menu da barra de Projetos.

### Correções

- **Login no console do CLIProxyAPI:** a verificação de status chamava a API de gerenciamento sem senha a cada atualização. O CLIProxyAPI contava isso como login falho e bloqueava 127.0.0.1 por 30 minutos, então a senha correta parecia recusada.

### Plataformas

Windows e Linux. O macOS continua pausado.

### Instalação

Os dados existentes do Chat Marks permanecem no diretório de usuário. O aplicativo e a extensão do navegador devem corresponder à mesma revisão.
