## Chat Marks 2.1.39.2 — Files and Review in any chat

**Files** and **Review** now appear as usable tools in the right panel, even
when the selected chat is not attached to a local project. Select either tool
and explicitly choose one of your existing Chat Marks projects. Your chat stays
in its original location, and changing the selected chat retires the temporary
file-browser selection. Project folders still need to be approved by the app's
existing filesystem permissions.

Built on the official Chat On Steroids 2.1.39 release with the previously
integrated Chat Marks Modules, CLIProxyAPI and Agency Skills functionality.
No new third-party binaries or skills are bundled with this update.

### Installation

Use Settings > Activity > Update or download the Linux x64 Debian package
or AppImage. The app preserves existing projects, chat history, service
settings and your existing configuration. The matching Chromium extension ZIP
is available separately. Do not distribute unsigned Firefox XPI files.
