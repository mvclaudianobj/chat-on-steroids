## Chat Marks 2.1.36 — base inicial para testes de atualização

Primeira publicação manual do Chat Marks para Windows x64 e Linux x64, baseada no código 2.1.36 com a identidade visual Marks.

- Nome Chat Marks e ícone da marca no aplicativo e na extensão.
- Atualizador direcionado para as Releases de mvclaudianobj/chat-on-steroids.
- Instalador Windows NSIS, pacote Linux DEB e Linux AppImage.
- Extensão do navegador e fontes correspondentes das bibliotecas nativas.
- SHA256SUMS.txt para conferir a integridade dos arquivos.

Verificações realizadas: typecheck, 62 testes de empacotamento e atualização, avisos de licença, runtime Linux empacotado, recursos Windows e integridade do instalador NSIS. O runtime Windows, a instalação Windows e o upgrade real ainda precisam de testes no sistema de destino. O instalador Windows foi gerado no Linux com o extrator nativo de desinstalador do electron-builder.

A atualização automática é suportada pelo instalador Windows e pelo AppImage. No DEB, a instalação da nova versão é manual. Esta versão será a base para testar o próximo upgrade, que deverá usar uma versão maior que 2.1.36.

Esta publicação contém somente os pacotes x64 indicados acima; não inclui pacotes ARM64 nem macOS. Publicação manual, sem executar os workflows de release.
