## Chat Marks 2.1.39.1 — community 2.1.39 and optional modules

Built on official Chat On Steroids v2.1.39, retaining its long-turn continuation fixes, regular-browser chat opening and richer diagnostic report.

### Marks features

- CLIProxyAPI optional module controls, separate UI activation and systemd controls, secure isolated management console.
- Agency Agents remote catalog, individual opt-in installation and updates protecting local changes.
- Verified SHA256 Marks updater and upstream merge preflight.
- Module sources registry, with future channels explicitly not implemented.

### Deployment

Only publish installers built from the reviewed final commit and validated for their own platform. No unsigned Firefox XPI.
