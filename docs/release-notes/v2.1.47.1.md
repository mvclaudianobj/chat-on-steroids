# Chat Marks 2.1.47.1 — integration candidate

## Highlights

- Incorporates community v2.1.47: scheduled runs, changed-file summaries on answers, commit/push/pull-request actions from Review, and configurable chat style.
- Retains Chat Marks integrations: Jarvis, Empresa, notifications, optional external modules, the WhatsApp approval bridge, and Android companion source.
- Keeps the Chat Marks brand and the 12-language renderer catalogs.

## Verification boundaries

- This is an integration candidate, **not** proof of a real WhatsApp grant, external delivery, VPN connection, remote control session, or Android APK.
- A disappearance of an approval card is not a host authorization receipt. Network and remote actions still require separate approval and physical testing.
- Linux packaging and isolated smoke tests must pass before promoting this candidate to stable.

## Safety

The optional Firefox VPN and TwinDesk integrations do not start VPN routes or remote sessions automatically. Installed production packages and user sessions are not changed by building this release.
