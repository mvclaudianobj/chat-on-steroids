## ChatMarks 2.1.51.3

ChatMarks revision 2 follows the community `main` tip `a07c8a2157f23e2ce5ace1ae26a601371474c1f2`, including the community changes after tag `v2.1.51`.

### Included community updates

- Show and manage scheduled messages across chats from one Scheduled list.
- Search complete chat histories with bounded index reads and recover interrupted search indexes after restart.
- Preserve Compact & Resume's own project brief correctly across reloads.
- Include the community's scheduled delivery recovery, tests, documentation and current README updates.

The integration retains ChatMarks identity, MarksPanel access control, MarksCode and other local modules. The upstream changes were merged with manual conflict resolution; see the worktree audit for the compatibility decisions and validation evidence.


Mozilla already has Firefox add-on version 2.1.51.2, so this Marks revision publishes the matching 2.1.51.3 add-on version. Existing app and Debian upgrade identifiers remain stable.
