## ChatMarks 2.1.51.4

Fixes Linux update discovery for older Chat Marks installations. Releases keep `ChatMarks-Linux-x64.deb` and also include `Chat-Marks-Linux-x64.deb` as a checksum-verified copy, so older app versions can find the update under the filename they expect.

The Linux package identity remains `chat-on-steroids` so existing Debian installations continue to upgrade in place.
