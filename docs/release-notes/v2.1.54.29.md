## Chat Marks 2.1.54.29

Move a linked chat between account slots through a durable Compact & Resume. The destination receives a saved-history brief with an explicit migration instruction; when its native project is not linked, the app creates and verifies that project before sending the first message. The original session remains in its slot until the destination confirms the new conversation.

Keep Awake is now opt-in for new or missing settings, and its operating-system hold is released when work ends or expires, when session state cannot be read, and during shutdown. Saved choices remain intact.

WhatsApp can send `/msg coo-ext` to the exact CEO-bound coordinator and return the result after app-confirmed delivery and completion. `/aprovar todos` uses the existing native CEO confirmation and safe eligibility checks.

A proven pre-Send browser pickup timeout retries the same outbox message ID. Opening a recovery tab no longer blocks recovery of other messages.
