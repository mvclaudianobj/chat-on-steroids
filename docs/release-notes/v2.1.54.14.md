# Chat Marks 2.1.54.14

## Community v2.1.54, with safer agent queues and complete worker cleanup

This release combines the official Chat On Steroids v2.1.54 community release with the Chat Marks integration and fixes.

### Highlights

- **Three independent account slots.** Each slot uses its own browser profile and connection, with dedicated ports for slots 2 and 3.
- **Safer agent requests.** Unsent requests stay ordered and are combined before delivery. Acknowledged messages are not replayed, including across Compact & Resume.
- **End and archive all workers.** The app verifies each worker's exact owner and waits for its exact turn to end before finishing archive work. The interface explains why a worker is still pending.
- **Chats appear at startup.** Saved conversations load as soon as the app opens.

### Worker cleanup behavior

The explicit owner action retires the exact worker fleet, requests Stop for active turns, preserves histories and worktrees, and reports any work still pending. Local and ChatGPT archive actions follow only after a confirmed turn end. The durable provider intent can be reconciled after restart without replaying an acknowledged archive or overriding a later acknowledged restore.

### Validation

- TypeScript typecheck passed.
- Worker broker, cleanup, archive ledger, and renderer-focused tests passed with `--maxWorkers=2`.
- Full release suite and native package checks are recorded separately after they complete.
