## Chat Marks 2.1.54.32

### Highlights

- Restore Slot 2 and Slot 3 extension discovery by renewing a stale native proof and retrying only the assigned listener.
- Treat an extension profile without a saved slot as Slot 1, while preserving explicit slot and port selection.
- Route browser tools using the verified slot of the calling session.
- Remove unsent queue entries that remain pending for over 60 minutes; keep uncertain sends as cancelled receipts so they cannot be replayed.

This release includes the Chat Marks fixes for multi-slot browser routing and stale queued input cleanup.
